# 阶段 14：智能体工程（Phase 14: Agent Engineering）

> 现代 AI 工程的核心。从第一性原理构建智能体。

## 在 GitHub 开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 11 大语言模型工程（LLM Engineering）与阶段 13 工具和协议（Tools and Protocols）。

**第一课（First lesson）：** [智能体循环（The Agent Loop）](01-the-agent-loop/)

不需要学习完整阶段时，可选择两条聚焦路线：

- [智能体辅助工程（Agent-Assisted Engineering）](../../learning-paths/using-coding-agents.json)涵盖任务界定、仓库证据、执行框架（Harness）、隔离、验证、审查与持久反馈。
- [产品判断与交付（Product Judgment and Delivery）](../../learning-paths/shaping-the-build.json)涵盖成效、工作流发现、假设、切片、规格、指标、分阶段发布与反馈责任归属。

从仓库根目录运行以下命令：

```bash
python3 phases/14-agent-engineering/01-the-agent-loop/code/main.py
```

保留命令、退出码、思考—行动—观察（Thought-action-observation）轨迹、最终答案、
轮次数，以及结束运行的确切停止条件。

**下一步（Next action）：** 修改脚本化任务或轮次预算，预测影响，
然后继续学习 [ReWOO 与计划后执行（ReWOO and Plan-and-Execute）](02-rewoo-plan-and-execute/)。
