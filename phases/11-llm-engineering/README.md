# 阶段 11：大语言模型工程（Phase 11: LLM Engineering）

> 让大语言模型（LLM）服务于生产应用。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 10 第 01 至 05 课，或具备同等的分词（Tokenization）、
数据流水线（Data pipelines）、预训练（Pretraining）和规模扩展（Scaling）知识。

**第一课（First lesson）：** [提示词工程（Prompt Engineering）](01-prompt-engineering/)

从仓库根目录运行以下命令：

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

保留运行命令、退出码、生成的提示词元数据、测试结果，以及一次提示词修改和它引起的
输出差异。演示使用模拟的模型响应，
不需要 API 密钥。

**下一步（Next action）：** 解释哪个提示词变量改变了行为以及原因，然后
继续学习[少样本、思维链与思维树（Few-Shot, Chain-of-Thought and Tree-of-Thought）](02-few-shot-cot/)。
