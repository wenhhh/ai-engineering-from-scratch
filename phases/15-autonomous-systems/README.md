# 阶段 15：自主系统（Autonomous Systems）

> 无需人类干预也能安全运行的智能体。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 14 第 01 课，智能体循环（The Agent Loop）。

**第一课（First lesson）：** [长时程智能体（Long-Horizon Agents）](01-long-horizon-agents/)

在仓库根目录运行以下命令：

```bash
python3 phases/15-autonomous-systems/01-long-horizon-agents/code/main.py
```

记录运行命令、退出码、任务时间跨度预测和多步累积可靠性表（Compounded reliability table），
并写出一项你要求在长时间运行前落实的运行控制措施。

然后继续学习[自学推理（Self-Taught Reasoning）](02-star-family-reasoning/)。
