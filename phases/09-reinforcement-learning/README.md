# 阶段 9：强化学习（Phase 9: Reinforcement Learning）

> 在行动中学习的智能体。这是 RLHF 的基础。

## 在 GitHub 开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 1 的概率与分布，以及阶段 2 第
01 课的机器学习分类。

**第一课：** [马尔可夫决策过程、状态、动作与奖励](01-mdps-states-actions-rewards/)

在仓库根目录运行以下命令：

```bash
python3 phases/09-reinforcement-learning/01-mdps-states-actions-rewards/code/main.py
```

保留命令、退出码、随机与贪心策略的回报、价值网格，并用
一句话说明策略质量与期望回报的联系。

**下一步：** 改变折扣因子，预测价值变化，然后
继续学习[动态规划（Dynamic Programming）](02-dynamic-programming/)。
