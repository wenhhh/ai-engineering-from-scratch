**入门项目（Starter project）：** [终端原生编码智能体（Terminal-Native Coding Agent）](01-terminal-native-coding-agent/)

在仓库根目录运行：

```bash
python3 phases/19-capstone-projects/01-terminal-native-coding-agent/code/main.py
```

保留命令、退出码、最终计划状态、预算总计、轨迹事件，
以及接入真实模型之前你会改变的架构决策。
