# 第 16 阶段：多智能体与群体（Multi-Agent & Swarms）

> 协调（Coordination）、涌现（Emergence）与集体智能（Collective intelligence）。

## 在 GitHub 开始本阶段（Start this phase on GitHub）

**Prerequisites:** Phase 14 智能体工程（Agent Engineering）。首个 TypeScript 演示
需要 Node.js 20+ 和 `npx`。

**第一课（First lesson）：**[为什么需要多智能体（Why Multi-Agent）](01-why-multi-agent/)

从仓库根目录运行以下命令：

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

保留命令、退出码、单智能体与多智能体的 token 和工具调用
总数，以及一项能证明新增协调值得投入的权衡。
