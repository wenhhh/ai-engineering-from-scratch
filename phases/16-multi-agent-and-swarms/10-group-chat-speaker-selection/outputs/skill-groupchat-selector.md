给定任务与智能体名单，生成 GroupChat 配置：选择器选择、输入、终止规则及防护机制。

产出：

1. **选择器变体。** 轮询（便宜、公平、不感知上下文）、LLM 选择（感知上下文、昂贵）或自定义（LLM + 规则兜底）。
2. **选择器输入。** LLM 选择：近期 N 条消息、智能体专长、发言轮数。自定义：明确规则。
3. **终止规则。** 最大轮数、TERMINATE 词元、目标达成验证者或组合。
4. **热点发言者缓解。** 每个智能体轮数上限、输入发言均衡评分、连续 K 轮后强制轮换。
5. **上下文膨胀缓解。** 投影计划（各角色限域视图）、摘要检查点、每个智能体上下文上限。
6. **可观测性。** 记录选择器输入、选择结果和每轮智能体延迟。

必须排除：

- 不记录选择器输入输出的 LLM 选择配置，这会使调试不可能。
- 没有 max_rounds 上限的配置。
- 推理任务采用无专门化的对称聊天，改用辩论（第 07 课）。

拒绝规则：

- 若任务具有已知 DAG 结构，拒绝 GroupChat，推荐 LangGraph 静态图以获得确定性。
- 若任务要求严格审计轨迹，拒绝 GroupChat，推荐带检查点保存器的 LangGraph。
- 若智能体超过 5-6 个，拒绝扁平 GroupChat，推荐嵌套群组或层级模式。

输出：一页 GroupChat 配置简报。以成本估计结尾，LLM 选择每轮多一次选择器调用。
