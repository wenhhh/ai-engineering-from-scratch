给定协商或任务市场场景（双边议价、N 方拍卖、契约网分配），设计协议。

产出：

1. **机制。** 双边议价、N 竞标者拍卖、契约网广播或多方联盟，指出博弈。
2. **报价生成器。** 确定性（Zeuthen 让步、Rubinstein 均衡、简单线性调度）或 LLM 提示。默认确定性，除非报价必须是定性结构，如提案、角色分配。
3. **叙述层。** LLM 提供易读表述、说服战术、人设，明确它不决定什么。
4. **私有与公开通道。** 如何防止推理进入对方上下文？以“私有草稿”和“公开消息”两个字段实现。根据 arXiv:2503.06416，不可妥协。
5. **轮数上限。** 双边最多 3-5 轮。不可无界，无界会奖励从众、鼓励情绪化报价。
6. **保留价格与 BATNA 纪律。** 双方须知自身底价。对方试探时 LLM 叙述者不得泄露，按此验证所有发出消息。
7. **成交率监测。** 预期基线，引用协商基准数字（按 LLM 角色不同为 27%-89%），以及退化告警阈值。
8. **升级。** 低于阈值轮次、违反 ZOPA、对方违规时交给调解智能体或人类。

必须排除：

- LLM 计算数值报价且无确定性兜底，arXiv:2402.15813 显示成交率约 27%。
- 不分私有公开通道，对方会读到推理。
- 无界轮次，会确保产生从众驱动结果。
- 单个智能体同时持有买卖方状态的角色扮演议价。私有信息是机制本身，合并角色会消除它。

拒绝规则：

- 无数值收益（定性协商、合同条款），OG-Narrator 可能不适用，推荐结构化提案 + 模式验证。
- 无法独立草稿（单次 LLM 调用架构），明确泄露风险，推荐两次调用架构。
- 对抗协商中对方可能说谎，推荐调解智能体及报价日志审计。

输出：一页简报。先一句总结（“双边议价：Zeuthen 报价生成器 + LLM 叙述者，5 轮上限，独立草稿，成交率低于 85% 告警。”），再给八节，最后示例对方看到的消息与私有草稿内容。
