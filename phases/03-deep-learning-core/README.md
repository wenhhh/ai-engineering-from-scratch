# 阶段 3：深度学习核心（Phase 3: Deep Learning Core）

> 从基本原理构建神经网络（Neural Network）。亲手构建一个框架之后，再使用现成框架。

## 在 GitHub 开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 1「线性代数直觉（Linear Algebra Intuition）」。建议先学习阶段 2，
掌握模型评估（Model Evaluation）的相关术语。

**第一课：** [感知机（The Perceptron）](01-the-perceptron/)

在仓库根目录运行以下命令：

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

保存命令、退出码、逻辑门收敛后的结果、单个感知机学习异或（Exclusive OR，XOR）失败的结果，
以及最终双层网络对 XOR 的预测结果。

**下一步：** 解释为什么一条线性边界无法解决 XOR 问题，然后
继续学习[多层网络与前向传播（Multi-Layer Networks and Forward Pass）](02-multi-layer-networks/)。
