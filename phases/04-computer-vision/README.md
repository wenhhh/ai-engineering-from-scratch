# 阶段 4：计算机视觉（Phase 4: Computer Vision）

> 从像素出发，理解图像、视频与三维（3D）内容。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 1 第 12 课「张量运算（Tensor Operations）」和阶段 3 第 11 课
「PyTorch 入门（Introduction to PyTorch）」。第一个演示只需要 NumPy。

**第一课：** [图像基础（Image Fundamentals）](01-image-fundamentals/)

在仓库根目录运行以下命令：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

记录所用命令、退出码、HWC 与 CHW 形状、归一化后的通道统计量、
往返转换的像素差异，以及插值粗糙度。演示会生成确定性的合成图像，
不使用网络。
