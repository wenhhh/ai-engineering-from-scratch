# 阶段 5：自然语言处理，从基础到进阶（Phase 5: NLP, Foundations to Advanced）

> 语言是通向智能的接口。掌握其中的每一层。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 2 第 14 课，朴素贝叶斯（Naive Bayes）。学习第一课只需
Python 3.11+。

**第一课：** [文本处理（Text Processing）](01-text-processing/)

在仓库根目录运行以下命令：

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

保留运行命令、退出码、词元（Token）列表、词干（Stem）、词元的词典形式（Lemma），以及一个
词干提取（Stemming）会丢失语义、但词形还原（Lemmatization）能保留语义的示例。

**下一步：** 添加一个包含标点和不规则动词的句子，
检查结果，然后继续学习[词袋与词频–逆文档频率（Bag of Words and TF-IDF）](02-bag-of-words-tfidf/)。
