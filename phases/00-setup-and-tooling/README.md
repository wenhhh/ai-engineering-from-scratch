# 阶段 0：环境配置与工具（Phase 0: Setup & Tooling）

> 配好开发环境，为后续所有学习做好准备。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 无。开始学习需要 Git 和 Python 3.11 或更新版本。其他
工具仅在学习路线需要时安装。

**第一课：** [开发环境](01-dev-environment/)

在仓库根目录运行按学习路线执行的预检（Preflight）：

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

保留所用命令、仓库根目录这一工作目录、退出码、必需项检查
结果以及打印出的 `Next:` 命令。可选项缺失不算失败。

**下一步：** 修复所有必需项的失败，重新运行直到命令以退出码 0 结束，
然后继续学习 [Git 与协作](02-git-and-collaboration/)。

浏览[阶段 0 的完整课程列表](../../README.md#phase-0)或
[跨阶段路线图](../../ROADMAP.md)。
