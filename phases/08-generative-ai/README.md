# 阶段 8：生成式 AI（Phase 8: Generative AI）

> 创建图像、视频、音频、3D 及更多内容。

## 在 GitHub 开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 2 机器学习基础、阶段 3 深度学习核心，以及
阶段 7 第 14 课：从零构建 Transformer。

**第一课：** [生成模型分类与历史（Generative Model Taxonomy and History）](01-generative-models-taxonomy-history/)

在仓库根目录运行：

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

保留命令、退出码、密度估计、生成样本，并用一句话说明
隐式生成器（Implicit Generator）无法回答关于 `p(x)` 的什么问题。

**下一步：** 改变随机种子，比较密度估计，再继续
[自编码器与 VAE（Autoencoders and VAE）](02-autoencoders-vae/)。

浏览[阶段 8 完整课程列表](../../README.md#phase-8)或
[跨阶段路线图](../../ROADMAP.md)。

共 15 课，总计约 15 小时。每课交付详细文档、
可运行 Python 演示、图表，以及供智能体（Agent）使用的具名技能。
