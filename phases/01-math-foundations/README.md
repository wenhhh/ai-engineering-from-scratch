# 阶段 1：数学基础（Phase 1: Math Foundations）

> 通过代码而非教科书，建立对每种 AI 算法背后原理的直觉。

## 在 GitHub 上开始本阶段（Start this phase on GitHub）

**Prerequisites:** 完成阶段 0，或确认在仓库根目录下能够正常使用 Python 3.11+ 和 Git。

**第一课：** [线性代数直觉（Linear Algebra Intuition）](01-linear-algebra-intuition/)

在仓库根目录运行以下命令：

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

保留运行命令、退出码、归一化向量（Normalized Vector）的输出、投影残差（Projection Residual），
并用一句话解释为什么矩阵与向量的乘积对应一个神经网络层（Neural-Network Layer）。

**下一步：** 修改一个输入向量，预测结果并重新运行，
然后继续学习[向量、矩阵与运算（Vectors, Matrices and Operations）](02-vectors-matrices-operations/)。
