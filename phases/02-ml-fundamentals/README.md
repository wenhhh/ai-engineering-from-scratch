# 阶段 2：机器学习基础（ML Fundamentals）

> 经典机器学习（Machine Learning，ML）仍是多数生产环境 AI 系统的支柱。

## 在 GitHub 开始本阶段（Start this phase on GitHub）

**Prerequisites:** 阶段 1 数学基础（Math Foundations）与 NumPy。使用以下命令检查学习路径：
`python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route ml-foundations`.

**第一课：** [什么是机器学习（What Is Machine Learning）](01-what-is-machine-learning/)

在仓库根目录运行以下命令：

```bash
python3 phases/02-ml-fundamentals/01-what-is-machine-learning/code/ml_intro.py
```

记录命令、退出码、测试准确率（Accuracy）、随机基线（Random Baseline），并用一句话
解释训练得到的分类器为什么能超过这条基线。

**下一步：** 改变类别之间的间隔，预测准确率会如何变化，
再次运行，然后继续学习[从零实现线性回归（Linear Regression from Scratch）](02-linear-regression/)。
