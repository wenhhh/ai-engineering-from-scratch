上游本地核心运行使用 Python 3.12.12、Node 25.6.1、Rust 1.95.0 和 Go 1.26.0，平台为 macOS arm64。可选 Python SDK 套件使用隔离环境中的 Python 3.12。框架版本及安装命令固定在各项目的依赖文件中。项目持续集成另行使用 Python 3.12、Node 24、Go 1.23 和运行器提供的 Rust 工具链；本地通过不能证明远端持续集成的状态。

## 浏览器与交付物检查

首次验收时，上游在 1440x950 的浅色模式和 390x950 的深色模式下检查了实际托管的目录、试点及文档抽取页面，扩展了此前对两种主题和两种宽度的检查。全部 48 个项目页面分别打开，以测试动态提供器加载。全部 197 个机制图成功挂载，接受输入变更并更新可见计算结果，初始无错误。此前界面检查还覆盖项目筛选、阶段导航、浏览器历史、完成状态保存、录屏播放与停止，以及证明报告导入。

八个新增应用的输出分别在 1120 和 390 像素宽度下检查。文档审阅测试选中了 Unicode 字符之后的来源区间，下载实际审批文件，通过命令行应用审批，再次打开已审批页面时选择仍被保留。学习教练在浏览器中分别记录错误和正确答案；下载的作答事件经命令行重放后得到预期复习安排。

证明导入拒绝参考解答证据，接受完整的学习者模式质量检查报告。该检查工作区仅为测试界面而有意复制参考实现，不宣称任何学习者成就。完成证明仍是本地自报的社区记录，不能确认身份，也不能阻止用户复制代码或修改 JSON。

浏览器智能体适配器实际驱动 Chromium 访问本地夹具并捕获结果。Rust 执行器通过真实标准输入输出和伪终端进行测试。试点报告在 Chromium 中打开，检查了引用并展开轨迹。终端 GIF 根据捕获的命令输出生成；应用输出 GIF 使用真实浏览器帧。四份框架 GIF 记录当时的可选评分器，并区分核心测试与额外 SDK 测试数量。

## 审阅后的复核

修正后，投稿卡片、预算项目阶段 4 和语义检索阶段 3 通过了 12 组路由、宽度和主题检查，覆盖 1280 和 390 像素宽度及两种主题。托管的预算凭据使用 `events[].status`。语义图在可编辑示例中保留字面复数匹配，解释与文件夹具的差异，并将 `constructor` 和 `__proto__` 作为普通检索词正确排序。这些检查未发现页面溢出或控制台错误。

生成的会议 HTML 通过实际下载事件处理程序保留了批准和拒绝状态。混合提供格式错误与有效的 PR 候选项时，HTML 和 JSON 结果一致。真实浏览器智能体命令行程序用四步完成本地 Chromium 夹具，并生成有效截图；单独的损坏截图测试保留失败凭据。夹具成功不能证明一般浏览器操作准确率。

回归测试覆盖服务商 HTTPS 和重定向边界、真实传输重试后的网关请求重放、有界 HTTP 连接关闭、拆分的 UTF-8 请求体、可选云日志时间窗、原子补丁清理、根目录通配匹配，以及原生进程终端凭据。会遗漏已有阶段测试的单文件运行器覆盖配置已移除。全量评分还暴露了并行桌面夹具目录冲突；通过原子序列修复后，30 次重复集成运行的全部 150 项测试通过，随后才执行最终全量检查。

日历保留文档中明确限定的端点子集，包括全天事件不含结束边界的规则。数值抽取保留有限 Python 浮点数语法，并包含接受和拒绝用例。这两项审阅建议需要澄清契约，无需扩大解析器范围。可选 SDK 集成代码未改变，因此本次上游复核未重新运行这些路线。

## 集成与回归检查

持久化任务与评估集群实际运行子进程，在文档规定的边界崩溃，恢复持久化工作并拒绝过期完成结果。执行框架与网关二进制程序发出了真实回环 HTTP 请求，覆盖调用预算、独立凭据、期限和有界响应体。Mastra 在一个进程中暂停工作流，再由另一个进程恢复同一持久化运行。官方 MCP 客户端通过标准输入输出和 HTTP 测试了教学服务器。

跨项目检查包括将审计后的数据划分用于评估、将 PR 问题导入评审组、用原生 Rust 校验器读取已安装技能包，以及将研究报告交给评审器。独立应用审阅复现并修复了另外三项缺陷：较大的 CSV 标识被错误合并、已批准的抽取选择在导出时丢失，以及事故复盘文本遗漏审阅元数据。回归测试与原始复现均通过。

## 限制

上游未执行原生 macOS 桌面控制。夹具后端成功不能验证辅助功能权限或原生交互。可选框架套件导入并执行真实 SDK，模型为确定性的本地模型；未调用在线模型服务商、Bedrock 或其他云服务。语音测试通过受控响应验证真实 WAV 和 multipart 传输；离线转录文本由明确提供，因此这些测试不衡量识别准确率。视觉检索使用已提供的文字矩形区域，不宣称执行 OCR。

沙箱阶段讲授策略规划，未执行可选 Docker 探针。队列与评估集群恢复只覆盖本地文件系统上的协作进程，不覆盖分布式存储，也不保证外部副作用恰好一次。评估数据集是公开教学夹具，其分数不能证明未见数据上的表现。来源哈希绑定内容，不证明审阅者身份。本地草稿不发送邮件、不发布问题，也不改变账户日历。
