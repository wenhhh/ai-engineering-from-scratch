# 实践项目规划

目录共包含 **100 个项目：48 个可构建、52 个规划中**。下列规划描述未来工作，尚无可运行阶段、完成测试或完成证明。

`roadmap.json` 是目录的权威数据源。每份简介提供具体交付物、通过已有项目入门的路径，以及四个拟议里程碑。实现时可将里程碑展开为四至八个带测试的阶段。不承诺交付日期。

| 级别 | 可构建 | 规划中 | 合计 |
|---|---:|---:|---:|
| 1. 入门 | 7 | 6 | 13 |
| 2. 构建 | 15 | 15 | 30 |
| 3. 工程 | 16 | 13 | 29 |
| 4. 系统 | 7 | 14 | 21 |
| 5. 前沿 | 3 | 4 | 7 |

## 构建顺序

选择适合当前水平的项目，先完成链接指向的先修项目。链接注明先修项目是已可构建还是同样处于规划中。没有先修项目的入门规划，默认学习者熟悉所选语言的基础。每项未来实现都应先在原创本地夹具上产生实用结果，再解释一个可见失败，最后添加可复用导出或适配器。外部 SDK 和服务商验证仍需明确说明。

每份简介定义独立任务和验收边界。实现时应添加原创夹具、留出用例、有来源支持的讲解、可编辑机制图，以及真实输出录屏。参考链接用于说明协议和格式，不能据此认定规划工具已经实现。

## 第 1 级：入门

<a id="bookmark-path-organizer"></a>

### 书签阅读路径整理器

帮助读者从导出的杂乱书签中整理出实用集合。审慎规范化 URL，合并完全重复的链接，根据已保存的标题和笔记为用户定义的主题评分，再将可编辑的阅读路径导出为 HTML 和 JSON。

**独立重点：** 语义笔记检索用于查找段落；本项目整理链接集合，生成有顺序的阅读交付物。

**首个待实现演示：** 将十二条原创社区制图链接整理成简短的入门阅读路径，并解释重复项。

**Languages:** TypeScript

**交付物：** 独立阅读路径页面，以及保留原始 URL 的 bookmarks.json

**先修项目：** 无；从所选语言基础开始。

拟议里程碑：

1. 导入书签并保留原层级
2. 规范化链接并解释重复组
3. 为主题排序并组装阅读路径
4. 导出可编辑集合和进度文件

<a id="csv-repair-workbench"></a>

### CSV 修复工作台

帮助表格所有者通过明确的变换顺序，修复不一致的标签、日期和缺失值。预览每个被修改的单元格，将含糊情况留待审阅，再导出清理后的 CSV、可复用的变换配方和 HTML 对照页。

**独立重点：** CSV 问答工作台用于查询表格；本项目构建经过审阅、可以重放的数据清理流程。

**首个待实现演示：** 统一社区花园位置的三种拼写，同时保留两个含义不明的日期供审阅。

**Languages:** Python

**交付物：** cleaned.csv、recipe.json 和单元格级 HTML 前后对照报告

**先修项目：** 无；从所选语言基础开始。

拟议里程碑：

1. 分析各列并保留原始单元格
2. 提出明确的规范化规则
3. 预览变化并审阅含糊值
4. 导出可复用的修复配方和清理后的表格

<a id="download-folder-sort-desk"></a>

### 下载目录整理台

结合文件元数据、内容哈希和可解释的类别评分，帮助用户整理本地下载。生成无冲突的目标路径建议和重复文件组，再导出 HTML 审阅台及其他文件管理器可读取的 JSON 移动计划。

**独立重点：** 邮件分流审阅台处理邮件线程和回复；本项目处理本地文件标识、重复内容与目标路径规划。

**首个待实现演示：** 将原创示例目录中的活动讲义、图片和重复附件整理成可检查的计划。

**Languages:** Python

**交付物：** 可搜索的 HTML 归档计划、重复组和 moves.json

**先修项目：** 无；从所选语言基础开始。

拟议里程碑：

1. 清点文件并计算内容标识
2. 根据可见文件特征为类别评分
3. 规划目标位置并显示命名冲突
4. 导出经审阅、可供文件管理器使用的归档计划

<a id="glossary-hovercard-publisher"></a>

**首个待实现演示：** 将具有模糊、裁切和曝光变化的原创几何场景图片分组，同时把不同场景单独保留。

## 第 2 级：构建

<a id="api-tutorial-runner"></a>

### API 教程运行器

帮助文档作者验证一组 HTTP 示例。解析明确的请求块，仅替换此前响应中已声明的变量，并对本地夹具或明确选用的测试端点执行请求。生成关联来源的报告，找出过期示例，并允许助手提出待审阅的修正建议。

**独立重点：** MCP 工具发现工作台导入端点描述；本项目执行有顺序的教程，处理响应变量及关联来源的断言。

**首个待实现演示：** 重放虚构借阅 API 教程，定位因过期字段名而失败的第一个请求。

**Languages:** TypeScript

**交付物：** 可重放的请求清单、JUnit 结果和带注释的教程 HTML

**先修项目：** [JSON 结构输出守卫（JSON Schema Output Guard）](json-schema-output-guard/)

拟议里程碑：

1. 从原创教程提取明确的请求
2. 跨步骤解析带类型的变量
3. 向测试服务执行有界请求
4. 导出关联来源的失败记录和修正建议

<a id="catalog-record-linker"></a>

### 目录记录关联器

帮助图书管理员或组织者核对两份 CSV 导出中不一致的物品记录。利用规范化字段和词元相似度生成候选配对，收集明确的匹配决策，并导出保留来源的对应表及经审阅的合并目录。

**独立重点：** CSV 修复工作台变换单个单元格；本项目判断不同集合中的实体是否为同一对象。

**首个待实现演示：** 关联两份原创借阅目录中名称不同的物品，同时把一个近似匹配项保留为独立物品。

**Languages:** Python

**交付物：** HTML 配对审阅队列、crosswalk.csv 和 merged-catalog.json

**先修项目：** [CSV 修复工作台](#csv-repair-workbench)（规划中）

拟议里程碑：

1. 导入两份目录并保留稳定来源标识
2. 生成候选配对并解释相似度
3. 审阅匹配并解决字段冲突
4. 导出对应表和合并目录

<a id="chart-storyboard-builder"></a>

**独立重点：** CSV 问答工作台通过查询和表格回答问题；本项目讲授视觉编码、注释依据和可移植图表发布。

**首个待实现演示：** 使用两张图解释原创维修活动出席数据，并展示缺失一周数据如何改变叙述。

<a id="configuration-drift-explainer"></a>

### 配置差异解释器

帮助开发者比较声明的默认值、环境覆盖值和实际观察到的 JSON 配置。保留优先级与脱敏规则，指出被覆盖的值，并将每项解释关联到来源文件或变量名。导出的配置差异报告可供助手使用，无需向其提供密钥值。

**独立重点：** JSON 结构输出守卫检查数据结构；本项目通过分层优先级和环境差异解释最终生效值。

**首个待实现演示：** 比较两个原创环境，找出遮蔽共享超时设置的过期覆盖项。

**Languages:** Go

**交付物：** 脱敏配置差异和优先级证据 JSON

**先修项目：** [JSON 结构输出守卫（JSON Schema Output Guard）](json-schema-output-guard/)

拟议里程碑：

1. 加载具名配置层
2. 按优先级解析值并保留来源
3. 比较预期与实际生效值
4. 导出脱敏解释和 CI 结果

<a id="dependency-upgrade-impact-map"></a>

### 依赖升级影响图

使用提供的升级前后 API 签名和范围受限的源码解析器，帮助维护者审阅依赖升级。将变更符号关联到实际调用位置，区分已确认的不兼容与无法判定的用法，并输出定向测试清单。可选模型可以解释证据，但不能虚构被移除的 API。

**独立重点：** PR 评审报告器检查变更行；本项目将新旧依赖契约关联到整个仓库中的调用位置。

**首个待实现演示：** 修改原创库的函数签名，找出两个受影响的调用方，并保留一个无法解析的动态调用。

**Languages:** Python, TypeScript

**交付物：** 调用位置影响图、SARIF 问题记录和定向测试清单

**先修项目：** [PR 评审报告器（PR Review Reporter）](pr-review-reporter/)

拟议里程碑：

1. 读取提供的新旧 API 契约
2. 索引支持的导入与调用形式
3. 将变化的签名关联到受影响代码
4. 导出问题并明确列出无法判定的情况

### 灰度发布决策实验室

帮助团队判断智能体行为变化是否适合扩大流量。为请求分配稳定分组，对比候选与基线的错误和延迟窗口，区分证据不足与检查失败。导出可重放决策凭据及本地影子适配器，不执行部署也能运行策略。

**独立重点：** 执行框架评测台在固定数据集上比较策略；本项目研究序贯发布决策、分组分配和随时间积累的证据。

**首个待实现演示：** 按窗口重放原创基线与候选请求，先显示证据不足，再触发明确停止决策。

**Languages:** Python, Go

**交付物：** 灰度策略运行器、本地影子适配器，以及停止／继续／证据不足凭据

**先修项目：** [执行框架评测台（Harness Bench）](harness-bench/), [智能体追踪调试器（Agent Trace Debugger）](agent-trace-debugger/)

拟议里程碑：

1. 分配稳定分组并定义发布信号
2. 积累可比较的基线与候选窗口
3. 应用最小样本量和停止规则
4. 通过本地影子适配器重放决策

**范围限制：** 只导出建议。声明所选统计假设，不要把小窗口通过解释为普遍的发布安全保证。

<a id="secret-injection-sidecar"></a>

### 密钥注入辅助进程

帮助开发者将服务凭据排除在模型可见的工具参数和常规轨迹之外。构建本地代理，解析不透明句柄，将每个句柄绑定到目标与操作，并在网络边界注入环境变量提供的凭据。测试被回显的凭据标记，导出带有界响应过滤的决策凭据。

**独立重点：** 工具调用防火墙授权操作；本项目从面向智能体的接口中移除原始凭据，并测试代理的可观察边界。

**首个待实现演示：** 使用不透明句柄调用本地夹具，证明返回轨迹中没有出现被精确回显的凭据标记。

**Languages:** Rust, Python

**交付物：** 本地凭据代理、基于句柄的客户端适配器和脱敏请求凭据

**先修项目：** [工具调用防火墙（Tool Call Firewall）](tool-call-firewall/), [Rust 流式智能体执行器（Streaming Agent Shell in Rust）](rust-agent-shell/)

拟议里程碑：

1. 定义不透明句柄及绑定目标的授权
2. 在代理边界内部注入凭据
3. 运行响应与轨迹脱敏夹具
4. 集成只使用句柄的客户端

**范围限制：** 使用环境变量中的密钥和回环测试服务。精确标记过滤只能展示有限性质，不能保证任意上游服务绝不泄漏变形后的密钥。

<a id="signed-webhook-inbox"></a>

### 签名 Webhook 收件箱

帮助开发者将外部事件输入智能体工作流，既不丢失重试，也不接受被篡改的载荷。按原创签名方案验证原始正文，执行时间戳范围限制，并在派发前保存稳定投递标识。导出 HTTP 接收器和重放命令行程序，区分传输重试与新的业务事件。

**独立重点：** 持久化智能体任务处理提交后的工作；本项目在入站 HTTP 边界建立投递真实性、标识和重放行为。

**首个待实现演示：** 将同一原创事件投递两次，再修改载荷中的一个字节，检查哪些投递进入持久化收件箱。

**Languages:** Go

**交付物：** 本地 Webhook 接收器、投递台账和显式重放命令行程序

**先修项目：** [自纠正工作流钩子（Self-Correcting Workflow Hooks）](workflow-hooks/), [持久化智能体任务（Durable Agent Jobs）](durable-agent-jobs/)

拟议里程碑：

1. 保留原始请求字节和投递标识
2. 验证签名并检查时间戳范围
3. 用持久化收件箱去重重试
4. 重放已接受的投递并生成处理凭据

**范围限制：** 默认签名格式是明确编写的教学契约。任何服务商适配器都必须实现并测试该服务商的实际签名规则。

<a id="tenant-fairness-scheduler"></a>

### 租户公平调度器

帮助平台开发者在任务大小不同的租户间共享有限工作进程池。实现加权亏空调度、有界准入和老化机制，使用原创突发负载比较各租户的等待分布。导出队列适配器及工作负载凭据，明确展示饥饿和未使用容量。

**独立重点：** 智能体预算规划器统计调用方提供的用量和期限；本项目决定哪个租户获得下一个共享执行槽，并测量公平性。

**首个待实现演示：** 重放一个虚构租户的突发请求，同时让第二个租户提交小任务，比较两种队列策略下的等待时间。

**Languages:** Rust, Python

**交付物：** 公平队列适配器、工作负载重放命令行程序和逐租户等待／吞吐报告

**先修项目：** [持久化智能体任务（Durable Agent Jobs）](durable-agent-jobs/), [智能体预算规划器（Agent Budget Planner）](agent-budget-planner/)

拟议里程碑：

1. 表示租户队列及声明的任务成本
2. 实现加权亏空调度
3. 限制准入并检测饥饿
4. 在重放的突发工作负载上比较公平性

**范围限制：** 依据声明或实测的服务单位定义公平性，并显示成本估算误差。本地适配器不宣称提供分布式共识。

## 第 5 级：前沿

<a id="agent-resource-deadlock-lab"></a>

### 智能体资源死锁实验室

帮助开发者协调需要多个独占资源的智能体，例如浏览器会话与工作区。构建等待图，探索有界调度，比较有序获取与超时释放策略。导出死锁轨迹和资源协调器适配器，并提供明确的资源获取凭据。

**独立重点：** 持久化智能体任务协调队列租约；本项目研究任务持有多个稀缺资源并继续请求其他资源时出现的循环等待。

**首个待实现演示：** 重放两个本地智能体以相反顺序获取浏览器和工作区的过程，再演示一个能够完成的调度。

**Languages:** Rust, TypeScript

**交付物：** 有界调度探索器、死锁重放轨迹和资源协调器适配器

**先修项目：** [持久化智能体任务（Durable Agent Jobs）](durable-agent-jobs/), [多智能体代码评审组（Multi-Agent Code Review Panel）](multi-agent-code-review-panel/)

拟议里程碑：

1. 建立资源所有权与等待边模型
2. 探索有界交错执行并检测循环
3. 比较有序获取和超时释放策略
4. 导出协调器及可重放死锁证据

**范围限制：** 有界探索器只能证明实际检查过的调度。应明确定义资源语义，区分死锁、工作缓慢、饥饿，以及所有者崩溃后仍占用资源的情况。

<a id="judge-bias-calibration-lab"></a>

### 评审器偏差校准实验室

帮助评估者判断自动配对评审器是否适合自己的任务。隐藏候选身份，交换答案位置，运行原创长度反事实用例，并将决策与留出的人工参考判断比较。导出分歧和偏差明细，以及带版本的评分标准和评审器配置凭据。

**独立重点：** 报告证据评审器检查报告证据和引用支持；本项目评估评估者自身的可靠性与偏差。

**首个待实现演示：** 交换两个原创答案的位置，找出没有新证据却改变偏好的录制评审器。

**Languages:** Python, TypeScript

**交付物：** 配对评审运行器、偏差评分表和带版本的评分标准／配置包

**先修项目：** [报告证据评审器（Report Judge）](report-judge/), [数据集划分审计器（Dataset Split Auditor）](dataset-split-auditor/), [本地模型评估执行框架（Local Model Evaluation Harness）](local-model-eval-harness/)

拟议里程碑：

1. 创建匿名配对并隔离人工参考判断
2. 运行位置交换和长度反事实用例
3. 测量分歧及各切片偏差
4. 导出评分标准和留出验证证据

**范围限制：** 录制的评审器响应构成离线基线。任何在线模型评审器都必须保留模型与配置凭据；校准发现只适用于已测试的任务分布。

<a id="trajectory-counterexample-minimizer"></a>

### 轨迹反例精简器

帮助智能体开发者诊断依赖操作顺序的故障。表达审批先于副作用等有界时序规则，检查事件轨迹，在保留声明的因果依赖时移除无关事件。导出最小重放包，包含被违反的规则和精确事件标识。

**独立重点：** 智能体追踪调试器解释执行时间；本项目检查事件顺序性质，并自动缩减失败轨迹。

**首个待实现演示：** 将二十个事件的原创运行缩减到能复现过期审批违规的审批与副作用事件。

**Languages:** Rust, Python

**交付物：** 时序轨迹检查器、保留依赖的缩减器和最小重放包

**先修项目：** [智能体追踪调试器（Agent Trace Debugger）](agent-trace-debugger/), [工具调用防火墙（Tool Call Firewall）](tool-call-firewall/)

拟议里程碑：

1. 规范化事件和声明的因果依赖
2. 检查有界时序规则
3. 在不破坏先修条件的前提下缩减失败
4. 导出最小可复现违规记录

**范围限制：** 因果关系保留依赖已记录的依赖和支持的规则语言。最小轨迹仅相对于所选缩减器与重放判定器成立，不能证明全局最小。

<a id="transactional-workspace-patch-broker"></a>

### 事务式工作区补丁协调器

帮助并发编程智能体避免在多文件变更中途互相覆盖文件。将补丁包绑定到内容哈希，在私有版本化工作区应用，运行声明的检查，再通过切换一个工作区指针发布。导出事务 API、冲突证据和明确的回滚日志。

**独立重点：** 微型编程智能体讲授编程循环；本项目明确多个智能体产生相互重叠的多文件修改时的发布与冲突处理。

**首个待实现演示：** 让两个本地工作进程提出重叠修改，展示一次完整发布及另一个进程的版本冲突。

**Languages:** Rust, TypeScript

**交付物：** 工作区事务 API、可审阅补丁包和冲突／回滚日志

**先修项目：** [微型编程智能体（Tiny Coding Agent）](tiny-coding-agent/), [沙箱策略规划器（Sandbox Policy Planner）](sandbox-ladder/)

拟议里程碑：

1. 将多文件补丁绑定到输入修订版本
2. 在私有版本化工作区暂存修改
3. 拒绝冲突并运行声明的验证
4. 发布工作区指针并记录回滚

**范围限制：** 原子性只适用于版本化工作区指针及遵循该指针的读取方。不得宣称向已有检出目录进行任意多文件写入都是原子的。
