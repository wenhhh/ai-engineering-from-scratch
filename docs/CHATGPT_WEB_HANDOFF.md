完整翻译每一段信息，使用中文技术人员习惯的表达，不做摘要，不以批量替换术语代替翻译。专有概念使用“中文（English）”，如检索增强生成（Retrieval-Augmented Generation，RAG）；产品、模型、库、协议名称保留原名。

机器元数据字段 `Type`、`Languages`、`Prerequisites`、`Time` 保留字段名；Type 与语言枚举保留。自然语言字段值可译。认证评估的 `objective` 部分是自然语言关联值而非短 ID，需与对应路线学习目标保持完全一致，并保留双语英文原值。
