# 威胁与控制矩阵（Threat Control Matrix）

面向 MCPA“安全与治理”领域的一页参考，对齐 MCP 2026-07-28。列出已正确授权、采用无状态部署后仍面临的十类威胁、对应控制及实现参考。

## 十类威胁

| 威胁 | 表现 | 控制 | 参考位置 |
|---|---|---|---|
| 元数据投毒 | 工具描述或注解嵌入与其职责无关的指令 | 按不可信输入处理；注册及每次变化时扫描 | 本课 `scan_for_injection` |
| 结果中的提示词注入 | 成功 CallToolResult 含有试图改变模型行为的文字 | 结果与描述同样不可信，不因来自成功响应就增加信任 | 安全最佳实践，工具结果部分 |
| 获批后篡改 | 已批准名称、描述、结构定义或注解改变，名称常常不变 | 固定完整描述符哈希，变化时隔离并复审，不只检查名称 | 本课 `RiskGateway.observe` 与 `approve` |
| 工具遮蔽 | 多台服务器同名工具由发现顺序悄悄决定目标 | 添加稳定服务器标识前缀，不按到达顺序解决歧义 | 第 06 课角色拓扑、第 09 课清单审阅 |
| 混淆代理 | 代理被诱导代攻击者使用受委托权限 | 转发到第三方授权服务器前逐客户端取得同意，不仅信任静态 client id | 授权安全注意事项，混淆代理部分 |
| 令牌透传 | 向无关上游转发客户端面向 MCP 的 bearer 令牌 | 验证受众，获取独立上游凭据，不转发入站令牌 | 本课 `RiskGateway.call` 的上游检查；授权简报第 12 节 |
| requestState 篡改 | 修改应原样回传的 MRTR 状态以改变服务器行为 | HMAC 或 AEAD 完整性保护、主体绑定、短有效期、请求摘要和服务器端单次使用 | 第 14 课及 MRTR 安全注意事项 |
| SSRF（CIMD 获取、网络 $ref） | 盲目获取他人提供的元数据 URL 或结构 $ref | 不默认自动跟随网络引用；显式获取经过允许列表、私有地址阻断、HTTPS 与超时限制 | 本课 `find_network_ref`；SSRF 安全最佳实践 |
| DNS 重绑定 | 验证时解析为安全地址，请求时变为内部地址 | 检查 Origin，本地 HTTP 服务绑定回环，不仅信任 Host 请求头 | 第 19 课传输与请求头、Streamable HTTP 安全 |
| 供应链漂移 | 注册条目、软件包或运行端点在准入后独立变化 | 验证命名空间所有者，按摘要固定，并在准入后重新观察运行服务 | 第 30 课（`phases/13-tools-and-protocols/30-mcp-registry-supply-chain-and-drift`） |

## 三种拒绝通道

| 情形 | 通道 | 示例 |
|---|---|---|
| 请求自身格式错误 | JSON-RPC 协议错误 | 未知工具：`-32602` |
| 请求形态正确，但策略拒绝调用 | 带 `isError: true` 的正常结果 | 速率限制、定义漂移暂缓、令牌透传尝试 |
| 确实需要应用自定义代码 | 位于整个 `-32768` 至 `-32000` 范围之外的代码 | 很少需要，优先使用 `isError` |

不得发出 `-32000` 至 `-32019` 的旧版代码、已移除的 `-32002` 或 `-32042`，以及 `-32020` 至 `-32099` 中未定义的保留代码。希望模型读取的策略拒绝应使用 `isError`。

## 实施检查清单

- 批准时固定工具完整描述符，包括名称、描述、inputSchema 和注解，不只固定描述。
- 描述与结果进入模型前扫描嵌入指令；命中触发复审，不直接视为最终结论。
- 聚合工具名添加稳定服务器标识，防止互相遮蔽。
- 验证所有入站令牌受众，不原样转发上游；使用独立且面向上游的凭据。
- 将 `requestState` 作为攻击者可控制输入，保护完整性，绑定主体、有效期和请求摘要，服务器端限制单次使用。
- CIMD、结构 `$ref` 或重定向等网络目标，未经显式允许列表和私有、链路本地地址防护，不自动获取。
- 检查 `Origin`，本地 HTTP 服务绑定回环，防御 DNS 重绑定。
- 图标只使用 `https:` 或 `data:`，核查服务器同源要求，并按潜在可执行内容处理 SVG。
- 验证注册命名空间所有者，按摘要固定包和远程来源，准入后重新观察服务。
- 自动拒绝选用正确通道：格式错误用 `-32602`，策略拒绝用 `isError: true`，不在 `-32000` 至 `-32099` 中自创代码。
