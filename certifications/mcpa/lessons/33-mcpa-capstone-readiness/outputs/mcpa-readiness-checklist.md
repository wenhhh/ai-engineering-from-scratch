# MCPA 准备清单（MCPA Readiness Checklist）

对齐 MCP 2026-07-28 和 `certifications/mcpa/tracks/mcpa-f.json` 的考前检查。五个加权领域共 18 项目标，逐项对应可执行实践，并指向本课报文（`code/main.py`、`docs/en.md`）或首次讲授它的前课。完成实验后核对一次，考前再复查。

## MCP 基础（16%）

- [ ] 能解释 MCP 标准化的集成问题：N 乘 M 定制连接如何减少为 N 加 M，以及协议有意留给宿主的职责。第 02 课首次讲授，本课将其作为全部交互的背景。
- [ ] 能描述宿主、客户端、服务器、原语和无状态 JSON-RPC，说明请求为何不能依赖前次声明。第 04 课深入构建，本课每次处理自描述请求。
- [ ] 能分析版本管理及开放协议的互操作价值。本课首个请求使用 2025-11-25，收到 UnsupportedProtocolVersionError，修正后继续。
- [ ] 能阅读规范、历史和功能生命周期，区分当前、弃用与移除。第 01、05、15 课讲解；本课不调用已移除方法，并将 roots、sampling、logging 正确理解为弃用。

## 架构与组件（14%）

- [ ] 能读懂消息、工具定义、能力和清单的模式及结构化数据。restart_service 的 inputSchema 将缺少 environment 的调用变为 isError，避免静默成功。
- [ ] 能区分宿主、客户端和服务器责任及发现协商关系。server/discover 预先公布 tasks，每个后续请求仍独立声明能力。
- [ ] 能从用户请求经宿主、模型、客户端、服务器追踪结果回到上下文。第 10 课构建完整循环；本课 restart_service 展示请求、校验、同意及结果路径。

## 交互与执行（26%）

- [ ] 能使用请求、通知、订阅和 MRTR，并处理各结果类型。本课同次运行产生 complete、input_required、task 和 notifications/progress。
- [ ] 能区分版本、能力、头部及参数问题的错误通道。本课产生版本 -32022、能力 -32021、参数 isError；-32020 的头部核对另见第 19 课。
- [ ] 能从发现、选择到调用、用户输入、进度、取消和结果走完生命周期。scan_fleet_health 展示进度，restart_service 展示 MRTR，第二个诊断任务展示取消。
- [ ] 能识别工具、资源、提示词、补全、缓存、分页、传输和已弃用客户端功能。本课直接覆盖工具、缓存提示、stdio 风格与 HTTP；资源、提示词、补全和分页细节见第 12、13、15、20 课。

## 安全与治理（24%）

- [ ] 能指出宿主、客户端、服务器、模型及服务器内容之间的信任边界。第 22 课建立划分，本课 acknowledge_incident 在 HTTP 层执行相应 OAuth 检查。
- [ ] 能使用 OAuth、注册、权限范围和同意限制服务器访问。本课拒绝异受众令牌并接受匹配令牌；完整授权注册见第 23、24 课。
- [ ] 能为工具投毒、注入、令牌误用和过宽授权选择控制。restart_service 要求已声明能力、签名 requestState 和显式 accept；更多控制见第 26 课。
- [ ] 能设计可追踪、归因和审阅的日志。本课跨跳保留追踪 ID，哈希链校验通过，并能定位局部篡改。整体防重写和截断保护仍需外部可信证据。

## 用例与生态（20%）

- [ ] 能映射团队的角色、职责、治理和采用路径。第 28 课展开，本课 incident-console 是用于练习运维流程的模拟服务器。
- [ ] 能按工作选择原语与扩展：快速只读扫描用普通调用，敏感重启用 MRTR 同意，长诊断用 tasks。更多用例见第 29 课。
- [ ] 能分析客户端、服务器、SDK、扩展、网关与目录间的可移植性。第 30—32 课展开；本课只在双方声明后使用 tasks，演示相应协商机制。

## 最后复习的易错点

- 未知工具为 -32602；-32601 仅表示 JSON-RPC 方法本身未知。
- 工具模式校验失败返回 isError true 的正常结果，不返回协议错误。
- 2026-07-28 没有 initialize 握手或协议会话，每个请求携带自己的版本和能力。
- MRTR 重试使用新 JSON-RPC ID，并原样回传 requestState。
- 资源未找到使用 -32602；确需应用自定义代码时，选择 JSON-RPC 保留区间之外，不使用旧版 -32000 至 -32019 或未定义的 -32020 至 -32099。
- Roots、sampling、logging 已弃用但仍可用，新设计应考虑迁移方向。
- 为某个受众签发的令牌不能被另一资源服务器接纳，也不能直接透传到不匹配上游。
- cacheScope public 允许共享响应，不意味着可以跳过访问控制。
