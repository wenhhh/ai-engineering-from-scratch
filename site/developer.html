从零开始的 AI 工程（AI Engineering from Scratch）

开发者资源

这是《从零开始的 AI 工程（AI Engineering from Scratch）》的机器可读入口。课程为静态开源内容，通过只读内容表示 API 面向智能体（Agent）和开发者工具提供访问。请从 llms.txt, 开始，它将课程映射到规范页面及原始 Markdown 源文件。

稳定资源

  • /llms.txt 是面向智能体（Agent）的课程地图。
  • /sitemap.xml 列出规范的公开 URL。
  • /openapi.json 描述只读资源接口。
  • /api/v1/markdown 根据 path 查询参数选定公开导航页面，返回其 HTML 或 Markdown。
  • /catalog.html 是供人阅读和搜索的课程目录。
  • GitHub 是课程、代码、测验和可复用交付物（Artifact）的权威来源。

Markdown 内容协商（Content negotiation）

请求首页或主要导航路由时，若携带 Accept: text/markdown，将收到智能体地图，响应类型为 Content-Type: text/markdown。响应根据 Accept 区分，避免缓存混淆 HTML 与 Markdown 表示。

内容表示 API 接受 GET 和 HEAD。响应包含 X-API-Version: 1；HEAD 返回相同元数据但不含响应体。不支持的内容表示或方法将收到 RFC 9457 问题详情（Problem details）。页面不存在时，仍为读者和智能体提供 HTML 或 Markdown 恢复链接，并为其他 API 客户端提供问题详情。

/api/markdown 保留为兼容别名。新增兼容功能仍位于 /api/v1/markdown；破坏兼容性的内容表示变更需要新的版本路径。此 API 不实施按客户端限流，因此不提供配额响应头。

模型上下文协议（MCP）状态

网站目前不提供托管的模型上下文协议（Model Context Protocol，MCP）服务器或需认证的产品 API。课程会教授如何构建和运维 MCP 服务器，相关交付物位于仓库中。远程可流式 HTTP（Streamable HTTP）MCP 端点需要独立的产品决策、认证策略及运维负责人。
