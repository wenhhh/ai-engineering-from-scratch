Claude 认证助理基础级（Claude Certified Associate - Foundations）

Claude 认证助理基础级（Claude Certified Associate - Foundations）: 在业务、研究、分析和提升生产力的工作流中，安全且有效地使用 Claude。 面向运营、项目、销售、市场、财务、支持、研究及其他知识工作专业人员，不要求软件开发经验。

  • 学会决策，而不只是记住术语（Study the Decisions, Not the Vocabulary）
  • 选择足以承载工作的最小产品形态（Choose the Smallest Surface That Can Carry the Work）
  • 将能力投入到失败代价高的地方（Spend Capability Where Failure Is Expensive）
  • 将请求转化为可测试的契约（Turn a Request Into a Testable Contract）
  • 将每项事实放入合适的上下文（Put Each Fact in the Right Kind of Context）
  • 验证主张，而不是相信自信语气（Validate the Claim, Not the Confidence）
  • 用授权约束能力（Put Authority Around Capability）
  • 先设计交接，再设计自动化（Design the Handoff Before the Automation）
  • 交付一周工作，而非完美提示词（Ship a Week of Work, Not a Perfect Prompt）

模型上下文协议助理认证（Model Context Protocol Associate）

模型上下文协议助理认证（Model Context Protocol Associate）: 证明你理解模型上下文协议的工作原理：宿主、客户端、服务器和工具，连接各组件的消息流与原语，以及保障连接安全的信任边界。 需要将智能体连接到外部系统，并理解协议原理与组件通信方式的 AI 工程师、平台工程师和 AI…

  • MCPA 考试大纲应指导学习预算，而非充当勾选清单
  • 阅读 MCP 规范（Reading the MCP Specification）
  • MCP 解决的集成问题（The Integration Problem MCP Solves）
  • JSON-RPC 消息封套（The JSON-RPC Envelope）
  • MCP 的无状态核心（The Stateless Core of MCP）
  • 区分现代与旧版 MCP 服务器（Telling a Modern MCP Server From a Legacy One）
  • 宿主、客户端与服务器：MCP 的进程拓扑（Hosts, Clients, and Servers: MCP's Process Topology）
  • 发现服务器并协商能力（Discovering a Server and Negotiating What It Can Do）
  • 工具定义中的契约（The Contract Inside a Tool Definition）
  • 像评审者一样阅读服务器清单（Reading a Server Manifest Like a Reviewer）
  • 模型交互流程（The Model Interaction Flow）
  • 工具原语：执行动作并读取结果（The Tools Primitive: Calling Actions and Reading Their Results）
  • 资源：无状态服务器中的可寻址内容（Resources: Addressable Content for a Stateless Server）
  • 提示词模板与参数补全（Prompt Templates and Argument Completion）
  • 多轮往返请求与信息征询（Multi Round-Trip Requests and Elicitation）
  • 已弃用但仍可用：Roots、Sampling 与 Logging（Deprecated, Not Removed: Roots, Sampling, and Logging）
  • 订阅流：通知、进度与取消（The Subscription Stream: Notifications, Progress, and Cancellation）
  • 工具调用生命周期（The Tool Invocation Lifecycle）
  • 请求失败的两个通道（Two Ways for a Request to Fail）
  • 传输与 HTTP 请求头契约（Transports and the HTTP Header Contract）
  • 缓存新鲜度与游标分页（Cache Freshness and Cursor-Based Pagination）
  • 长时间运行的工作与任务扩展（Long-Running Work and the Tasks Extension）
  • MCP 交互中的信任区域（Trust Zones in an MCP Exchange）

学习方式

学习、构建，在压力下作出决策。

01

学习机制

学习考纲背后的概念，而不是背诵产品词汇。

02

构建系统

通过实验与交付物（Artifact）落实架构、工具、评估（Evaluation）与安全决策。

03

训练判断力

通过原创场景、限时模拟考试及领域反馈，找出决策中的薄弱环节。
