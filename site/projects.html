构建真正有用的项目。

将课程知识变成可运行的交付物：报告生成器、记忆服务器、任务队列或智能体。你逐阶段构建，评分器检查各阶段，导师提供学习指导。

从第一个项目开始 提交你的项目
使用方法

三个命令，开始一个项目

根据任务选择 Python、Rust、TypeScript 或 Go。核心测试可离线运行；可选框架实验会列明依赖。

  1. 01

    创建工作区

    复制起始文件。每个占位函数都给出需要实现的精确签名。

    python3 scripts/project_test.py research-report-agent --init my-report-agent
  2. 02

    运行评分器

    每次构建一个阶段。评分器检查当前实现及全部前置阶段。

    python3 scripts/project_test.py research-report-agent --stage 1 --path my-report-agent
  3. 03

    跟随导师学习

    在 Claude Code 中按阶段学习，获取提示和反馈。

    /build-project research-report-agent
分级项目目录

选择你的级别

共五个级别，每级增加一类工程能力。新编写或提交的项目会加入对应级别。

社区贡献

把你的实用项目加入目录。

社区项目与核心项目采用相同结构：project.json、包含课程正文、起始代码和测试的各阶段，以及参考实现。项目会展示你的 GitHub 用户名。

  • 交付可用成果，不只演示聊天
  • 每个阶段都有可离线通过的测试，无需 API 密钥
  • 提供独立评估夹具，并说明分数能够证明什么
  • 提供原创实现，并链接官方规范与研究资料

复制后，先将 projects/my-project/project.json 中的 id 设为 my-project，再运行评分器。

cp -r projects/_template projects/my-project
python3 scripts/project_test.py my-project \
  --all --solution --strict
