硬件实验室合作伙伴（Hardware Lab Partner）

硬件企业可以赠送生产级图形处理器（GPU）、AI 工作站、存储设备、网络设备或边缘系统来赞助课程。硬件交付后归维护者所有。

维护者可根据课程和仓库工作的需要，使用、改装、进行基准测试、改变用途或淘汰受赠硬件。提供方可在赞助页及相关工作中获得最长 12 个月的硬件实验室合作伙伴署名。硬件赞助不会自动获得现金赞助档位。

寄送硬件前，请先联系维护者。

不可协商的规则（Hard rules）

以下规则不接受协商。不接受这些规则的赞助申请将被婉拒。

  1. 课程正文不放置赞助内容。 标志只出现在 README 赞助区、课程站点的赞助页和 BACKERS.md 中，绝不进入 phases/**/docs/en.md、outputs/、代码示例或其他承载课程内容的位置。
  2. “受支持的服务提供商”不等于“推荐”。 每节 API 课程都通过同一接口展示至少三家服务提供商。赞助商与其他提供商并列，不会被标为默认选项、优先选择，也不会成为“我该用哪家”的指定答案。
  3. 不接受赞助商撰写的内容。 每节课程均由维护者编写。赞助商只能审核集成拉取请求的技术准确性，不能提出叙事方向、规定如何讨论取舍或否决比较内容。
  4. 赞助商没有路线图否决权。 铂金赞助商和其他人一样可以提交路线图建议，最终发布内容由维护者决定。
  5. 编辑立场冲突时，30 天内终止合作。 若赞助商施压，要求维护者偏袒某种内容，将在 30 天内终止赞助并按比例退款。标志在下一次站点部署时移除。
  6. 拒绝利益冲突。 本课程不接受产品与课程原则直接冲突的赞助商，例如闭环氛围编程工具（Vibe-coding tools）、宣扬供应商锁定（Vendor lock-in）的产品，以及忽视可观测性（Observability）或拒绝采用开放格式交付的智能体（Agent）产品。是否拒绝由维护者自行决定。
  7. 仅接受现金或经批准的硬件。 不接受服务额度、股权、“代做开发者关系（DevRel）”、赞助商撰稿及捆绑交易。硬件必须遵守上方书面的硬件实验室合作伙伴政策。

潜在赞助商的其他提案（Counter-proposals from prospective sponsors）

公司如有其他诉求，请先阅读赞助档位和不可协商的规则，并在第一封邮件中提出明确的档位与期限。不要以“免费额度换首屏展示位”或“由我们自己编写集成课程”作为开场；这些形式已被上述规则排除，回复也只会引导你回到本页。

上述档位价格参考两类来源：同类开源项目的公开赞助页面，以及月访客 10 万至 25 万的开发者媒体常见赞助位价格。受众数据和 GitHub 星标数核实于 2026-08-29。

可比较的开源项目价目表：

  • $5,000 铂金档与 Vue 钻石档相当。50.7K 星标、114.6K 月访客，加上专门课程和首屏展示位，构成定价依据。
  • $10,000 钻石 / 冠名合作伙伴档每年仅设一个独家名额。定价考虑了 50.7K 星标、2026-03-31 至 2026-08-29 期间的 477.7K 访客和 765.6K 页面浏览量、冠名展示、季度报告，以及维护者编写的集成内容。

赞助资金用途（What sponsorship pays for）

按新增资金的支出优先级排列：

  1. 维护者编写新课程和处理问题单所需的时间。
  2. 站点托管、域名和内容分发网络（CDN），包括 Vercel 和自定义域名。
  3. 图表创作工具、字体授权和设计素材。
  4. 当某个阶段超出维护者的专长范围时，向受邀课程评审者支付一次性的研究或内容费用。
  5. 为已开放超过 30 天的特定问题单提供贡献者悬赏。

成为赞助商（Becoming a sponsor）

  1. 选择上方的一个档位。
  2. 通过 GitHub Sponsors 订阅。
  3. 白银及以上档位需向维护者发送邮件，提供标志（优先使用 SVG）、标志的跳转 URL，以及承诺的合作期限。
  4. 标志将在下一次站点部署时上线，通常在 48 小时内。
  5. GitHub Sponsors 自动开具收据和发票。

硬件合作伙伴按独立的硬件实验室合作伙伴流程办理，寄送设备前须同意书面条款。

终止赞助（Becoming an ex-sponsor）

在 GitHub Sponsors 控制台单击即可取消。当前计费周期结束后，标志将在下一次站点部署时移除。不追讨既有权益，不进行退出访谈，也不影响彼此关系。赞助用于资助课程，不是购买私人关系。
